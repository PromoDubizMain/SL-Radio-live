# **App Name**: Biz FM Radio

## Core Features:

- Stream Radio: Stream Biz FM radio.
- Play/Pause Control: Implement play/pause functionality.
- On/Off Control: Implement on/off toggle to start/stop the radio.
- Volume Control: Implement volume control with a slider.
- Radio Information: Display the Biz FM logo and name.

## Style Guidelines:

- Primary color: A vibrant blue (#29ABE2) to reflect the dynamism and reliability of business news.
- Background color: A dark gray (#333333) provides a professional and modern backdrop.
- Accent color: A light blue (#B4DDFC) used for interactive elements and highlights.
- Font: 'Inter' sans-serif font for both headlines and body, ensuring readability and a clean interface.
- Use simple, clear icons for play/pause, on/off, and volume control. Outline style.
- A clean, minimal layout with prominent play/pause controls and volume slider. Logo and station name at the top.
- Subtle transitions on play/pause and on/off states.
